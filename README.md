## 🌊 01 — PROJECT OVERVIEW

### TITANIC DATA ANALYSIS

A Python-based exploratory data analysis project focused on understanding passenger survival patterns through data cleaning, statistical analysis and visualization.

This project loads the Titanic dataset, examines its structure, handles missing values and analyzes survival patterns across different passenger groups.
### What the project covers

| Area                        | Description                                                |
| :-------------------------- | :--------------------------------------------------------- |
| 📂 **Data Loading**         | Reads the Titanic CSV dataset using Pandas                 |
| 🔎 **Data Exploration**     | Inspects rows, columns, data types and missing values      |
| 🧹 **Data Cleaning**        | Handles missing `Age` and `Embarked` values                |
| 📊 **Statistical Analysis** | Calculates survival counts, rates and group-based survival |
| 👥 **Gender Analysis**      | Compares survival between male and female passengers       |
| 🎫 **Class Analysis**       | Examines survival across passenger classes                 |
| 📈 **Visualization**        | Creates charts for survival, age and correlations          |

## 🧠 07 — CORE IMPLEMENTATION

### 📂 Data Loading

```python
import pandas as pd

df = pd.read_csv("Titanic-Dataset.csv")
```

### 🔎 Data Inspection

```python
print(df.head())
print(df.info())
print(df.isnull().sum())
```

### 🧹 Missing Value Handling

```python
df["Age"] = df["Age"].fillna(df["Age"].median())
df["Embarked"] = df["Embarked"].fillna(df["Embarked"].mode()[0])
```

### 📊 Survival Analysis

```python
print(df["Survived"].value_counts())
print(df["Survived"].mean() * 100)

print(df.groupby("Sex")["Survived"].mean() * 100)
print(df.groupby("Pclass")["Survived"].mean() * 100)
```

The implementation follows the actual structure of the submitted Python script.
